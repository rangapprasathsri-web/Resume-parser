# Evidence-First Resume Parser & ATS Analyzer

## 1. What We Built

We built an evidence-first resume parsing and ATS matching system that extracts structured information from resumes and compares it against job descriptions. The system processes PDF and DOCX resumes, segments content into logical sections, extracts candidate information, and generates ATS compatibility scores. Every extracted field includes evidence from the resume text, making the output transparent and verifiable. The ATS engine uses exact matching, alias normalization, and fuzzy matching to improve requirement detection. The system also ranks candidates and highlights missing skills or qualifications.

## 7. How to Run It

1. Upload a PDF or DOCX resume.
2. Paste or upload a Job Description.
3. Click Analyze Resume.
4. Review ATS score and extracted fields.
